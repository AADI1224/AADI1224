## 🚀 Professional Experience

### Data Engineer — Tata Consultancy Services (TCS)

**Project: Dell Boomi to AWS Glue Migration**  
*April 2026 – September 2026*

Contributed to migrating approximately **200 legacy Dell Boomi jobs to AWS Glue** using PySpark and SQL across five regions: AU, CN, CH, EU, and MX.

**Key Contributions**

- **Data Pipeline Development:** Developed and enhanced AWS Glue jobs using PySpark and SQL to process data from Amazon S3 landing buckets and write transformed outputs to discovery buckets.
- **Schema-Drift Handling:** Addressed inconsistent schemas and data types across Parquet files using PySpark-based type conversions.
- **Regional Ownership:** Developed the Canada-region Glue job using existing references and AI-assisted coding tools; served as the regional point of contact for troubleshooting and team queries.
- **Workflow Automation:** Created Lambda-based scheduling configurations for five job sets, including 20 JSON configuration files supporting full and incremental load start-stop schedules.
- **Infrastructure as Code:** Created infrastructure repositories for Glue jobs, crawlers, Lambda triggers, IAM roles, S3 policies, and IAM user policies using existing CloudFormation templates.
- **Data Validation:** Queried legacy and migrated outputs using Amazon Athena and compared exported results using the team's Python-based record-validation utility.
- **Deployment Workflow:** Contributed to CI/CD deployments, pull requests, and controlled production change requests.
